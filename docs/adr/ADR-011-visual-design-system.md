# ADR-011：以 DESIGN.md 为视觉设计令牌来源，并在应用层扩展

- 状态：Accepted
- 日期：2026-08-10

## 背景

`DESIGN.md` 提供了一套完整的令牌体系：色板、字阶、圆角、间距、层级、响应式断点。
把它直接采纳为 `packages/ui` 的设计来源可以省掉从零设计的成本。

但它描述的是**一个营销站**，其 Known Gaps 章节自述不覆盖表单校验状态、产品级组件与
动效。本项目是稠密数据编辑器：要渲染 10,000 条规则（NFR-PERF-04）、要表达 Error /
Warning / Info 三级问题（FR-VAL-01）、要满足 WCAG 2.2 AA（PRD §11.6）。直接照搬会同时
带来无障碍不达标和组件缺口。

## 决策

### 1. 采纳令牌体系

`spacing`、`rounded`、`typography` 字阶、elevation 哲学（色块优先、阴影稀少）、响应式
断点全部照搬，作为 `packages/ui` 的令牌来源。

### 2. 对比度修正（AA 是硬约束，优先于原色值）

按 WCAG 2.x 相对亮度公式计算，原色板有三处不达 AA 4.5:1：

| 组合                             | 用途                 | 对比度     | 判定       |
| -------------------------------- | -------------------- | ---------- | ---------- |
| `body` #3d3d3a on `canvas`       | 正文                 | 10.34:1    | 通过       |
| `muted` #6c6a64 on `canvas`      | 次级文字             | 5.13:1     | 通过       |
| `on-dark-soft` #a09d96 on 暗面   | 暗面正文             | 6.62:1     | 通过       |
| `primary` #cc785c on `canvas`    | `text-link` 内联链接 | **3.11:1** | **不通过** |
| 白色 on `primary` #cc785c        | 主 CTA 标签 14px/500 | **3.28:1** | **不通过** |
| `muted-soft` #8e8b82 on `canvas` | `caption` 13px       | **3.23:1** | **不通过** |

修正规则：

- **`primary-active` #a9583e 升为承载文字的珊瑚色**，`primary` #cc785c 仅用于大面积
  填充与非文字表面。验证：白字 on #a9583e = 5.06:1，#a9583e on `canvas` = 4.80:1，均达 AA。
- `muted-soft` 不得用于 13px 说明文字，caption 一律改用 `muted`；`muted-soft` 仅保留
  给装饰性元素与非文本内容。

`DESIGN.md` 自称 36px 图标按钮「slightly under WCAG 44」是 AAA（SC 2.5.5）口径；AA 的
SC 2.5.8 只要求 24×24，36px 达标，**不需要修改**。

### 3. 字体替换

Copernicus 与 StyreneB 是受限商业字体，`DESIGN.md` 自述不可作为公开 web font。采用其
文档给出的开源替代：**EB Garamond / Cormorant Garamond**（显示体）、**Inter**（正文）、
**JetBrains Mono**（代码）。

### 4. 品牌资产隔离

不使用 Anthropic 四芒星 spike-mark 或任何其它他方品牌标识。README 已声明本项目与
MetaCubeX 无隶属关系，再引入第二个他方品牌视觉只会加重误认。项目使用自有标记。

### 5. 应用层扩展（`DESIGN.md` 未覆盖，由 `packages/ui` 定义）

| 扩展         | 原因                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------- |
| 密度尺度     | 96px 段落节奏与 32px 卡片内边距是编辑排版；长列表需要独立的 compact 行高                           |
| 表单状态全集 | 原系统只有 `text-input` 与 `-focused`；需补 error / warning / disabled / readonly                  |
| 亮/暗主题对  | 原系统的暗色是"段落交替节奏"，编辑器需要整体主题切换                                               |
| hover 规范   | 原系统明令"Never document hover"；桌面端行操作、拖拽手柄、图标按钮必须有 hover 反馈                |
| 编辑器组件族 | 树视图、虚拟列表行、拖拽手柄与序号、差异增删色、关系图画布、分栏、Tab、Toast、右键菜单、严重级徽章 |
| 非颜色编码   | PRD §11.6 要求错误不得只用颜色表达，语义色必须成对配图标或文案                                     |

扩展令牌在 `packages/ui` 中必须显式标注来源，与照搬自 `DESIGN.md` 的令牌区分开。

### 6. CI 断言

令牌组合表跑自动化对比度检查，不达标即 fail。第 2 节的数值是人工计算结果，最终以该
检查为准。

## 结果

- 视觉基调（暖奶油底 + 珊瑚 + 深墨表面）保留；文字承载色改用 `primary-active` 后，
  珊瑚在小尺寸文字上略微变暗，属可接受代价。
- `DESIGN.md` 需从仓库根目录迁至 `docs/design-system.md`，并同步修改 `.prettierignore`
  中的 `DESIGN.md` 路径条目——该文件按原样保留，不参与格式化。
- 需要长期维护一份"原系统未覆盖"的扩展令牌集，二者边界不清会导致后续贡献者无法判断
  某个令牌能否改动。
