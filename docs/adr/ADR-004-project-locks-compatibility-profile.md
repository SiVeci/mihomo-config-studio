# ADR-004：项目锁定兼容档案，更新不自动迁移

- 状态：Accepted
- 日期：2026-08-10
- 来源：PRD §8.9 FR-UPD-05/06、§9.5、§17 ADR-004

## 背景

Mihomo 字段默认值和支持范围会变化。若应用或 Schema 更新后自动升级项目，
用户的配置行为可能在他不知情的情况下改变。

## 决策

每个项目在 `schema-lock.json` 中固定 `bundleVersion + compatibilityProfile`。

1. 安装新 Bundle **不改变**任何既有项目的档案。
2. 升级项目是用户的显式动作，且必须先展示迁移预览：新增字段、废弃字段、默认值变化、差异。
3. 破坏性迁移前自动创建快照（NFR-REL-01）。
4. 有损迁移标记为 Lossy，默认取消，必须显式确认。
5. 无法安全降级的字段进入隔离区，不静默删除。
6. 缺失所锁定的 Bundle 时项目进入**只读保护**并引导恢复，而不是用新 Bundle 强行打开。

## 结果

- 本地需要保留多个 Bundle（至少最近两份，FR-UPD-04），存储策略需要裁剪规则。
- 升级交互更复杂，但配置行为可预测。
