# ADR-005：不提供服务端订阅代理

- 状态：Accepted
- 日期：2026-08-10
- 来源：PRD §8.11、§17 ADR-005

## 背景

Web 端受 CORS 限制，无法直接抓取任意订阅地址。一个"帮用户抓取"的官方服务器可以绕过这个限制。

## 决策

**不建设**该服务。项目官方服务不提供开放订阅代理接口。

- P0：用户可以在 `proxy-providers` 中填写、修改、遮罩显示和复制订阅 URL；可导入本地 Provider 文件做结构预览。
- Web 端跨域失败时如实提示，不绕过浏览器安全策略。
- P1 可评估 Android 原生网络请求，但必须显式征得同意、禁止记录 URL、限制重定向次数与响应体大小。

## 原因

订阅 URL 本身就是凭据。代抓服务会把全网用户的订阅密钥集中到一台服务器上，
并同时引入 SSRF、被滥用为开放代理、带宽成本与合规风险。

## 代价

受 CORS 限制时，网页端不能直接预览部分远程订阅。这是有意接受的功能缺口。
