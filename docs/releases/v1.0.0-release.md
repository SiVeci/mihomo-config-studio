## 本版本要回答的问题

**附录 A 的 MVP Definition of Done 十条，能不能逐条签字？**

本版本不做新功能，只做反馈修复、文档与发布。任何"顺手加一个小功能"的诉求都应改期
1.x——1.0 的价值是可信，不是功能多。

| 内置模板内核测试通过率 | 100%                  | 内核测试矩阵                 |

| 默认配置内容网络上传   | 0                     | `no-network-egress` 守卫     |

### 2. 附录 A：MVP Definition of Done

十条逐条验收，缺一不可发布：

- [ ] 用户可在 Web 和 Android 完成新建、导入、编辑、保存和导出
- [ ] P0 配置模块具有图形化表单或明确的高级 YAML 入口
- [ ] 未知字段不会因编辑和导出而丢失
- [ ] 代理组和规则引用可追踪，重命名能正确级联
- [ ] 阻断错误能跳转到具体字段或 YAML 行
- [ ] 所有内置模板通过目标 Mihomo 内核配置测试
- [ ] Schema Bundle 可验证、安装、锁定和回滚，且不执行远程代码
- [ ] Web 可离线工作；Android 可通过系统能力打开、保存和分享文件
- [ ] 默认没有配置内容、订阅 URL 或密钥上传行为
- [ ] README、用户指南、Schema 贡献指南和隐私说明齐全

### 3. 文档四件套

| 文档            | 内容                                                                |
| --------------- | ------------------------------------------------------------------- |
| 用户指南        | 三条核心旅程（模板创建、导入已有配置、适配新版本，PRD §6.2）        |
| Schema 开发指南 | 模块结构（§9.3）、受限 DSL、如何本地预览与验证、如何提 PR           |

| 隐私与安全说明  | 本地优先边界、敏感字段处理、签名与更新机制，已有 `SECURITY.md` 扩充 |

README 与应用"关于"页面必须声明：本项目是社区工具，**与 MetaCubeX 官方无隶属或背书
关系**（PRD §2.3）。

### 4. 发布范围（PRD §16.3）

- [ ] 发布阻断项清零
- [ ] 官方样例与模板通过 Mihomo 测试矩阵
- [ ] 用户文档、贡献指南、Schema 开发指南和安全说明齐全
- [ ] **Stable 更新通道可用**

### 5. 用户体验指标（PRD §14.2）

作为验收参考，不作为阻断：

- 新用户在 10 分钟内通过模板完成首次有效配置。
- 高级用户可在不离开应用的情况下定位所有未知字段。
- 导出前的问题中心能够解释所有阻断错误。
- Schema 更新安装失败时用户配置不受影响。

### 6. 遥测

MVP **默认不开启遥测**。若未来加入匿名统计，必须单独征得同意，且只能记录功能事件和
性能数据，不能记录配置路径、值或 URL（PRD §14.2）。1.0 不引入。
