# Mihomo 配置工坊 v0.9.0-rc.1

面向 Web 与 Android 的、本地优先、Schema 驱动的 Mihomo 配置生成与管理工具。

**这是一个候选发布版本（Release Candidate），不是 1.0 正式版。** 本次发布的目的是
把 v0.6.0 Beta 以来积累的加固与功能收尾成一个可以公开验证、开始收集反馈的版本，
详见[需求追踪表](../requirements-traceability.md)与
[v0.9.0 执行计划](./plans/v0.9.0.md)。已知缺口见下方"已知缺口"一节——**本发布说明
不会把任何未完成的事说成已完成**。

## 这是什么，不是什么

**是**：一个图形化创建、导入、理解、校验、维护和导出 Mihomo YAML 配置的工具。

**不是**：

- 不运行 Mihomo 内核
- 不是代理 / VPN 客户端，**不申请 Android `VPNService` 权限**
- 不提供账号、云同步或在线配置托管
- 不通过项目服务器代抓订阅

配置数据默认只在本地处理。订阅 URL、密码、UUID、证书和私钥不会被上传到任何服务器。

## 下载与校验

本次发布包含两个产物，均可从本 Release 的 Assets 直接下载：

- `mihomo-config-studio-web-<version>.zip`：Web 构建产物，解压后可用任意静态文件
  服务器托管（需支持 Service Worker，见下方"离线与 PWA"）。
- `mihomo-config-studio-<version>.apk`：已签名的 Android 安装包。

`SHA256SUMS.txt` 附带两个产物的 SHA-256 校验值。下载后可自行核对：

```bash
sha256sum -c SHA256SUMS.txt
```

## Android 安装说明

本项目**不在应用商店分发**（[ADR-015](../adr/ADR-015-release-channel-and-license.md)，
仅 GitHub Releases + MIT 许可），安装 `.apk` 前需要在系统设置里为浏览器/文件管理器
临时开启"安装未知应用"权限。

**可自行复核本应用不申请 VPN 权限**：用 Android SDK 自带的 `aapt2` 对下载到的 APK
运行：

```bash
aapt2 dump permissions mihomo-config-studio-<version>.apk
```

输出中不应出现 `android.permission.BIND_VPN_SERVICE`，也不应出现
`READ_EXTERNAL_STORAGE`/`WRITE_EXTERNAL_STORAGE`/`MANAGE_EXTERNAL_STORAGE`/
`ACCESS_BACKGROUND_LOCATION`——这份白名单由
[`tools/android-manifest-check`](../../tools/android-manifest-check) 在构建期对源码清单与
产物本身各断言一次，本发布工作流已经跑过，此处的自行复核是可选的、面向不信任构建产物
的用户。

**最低支持版本**：Android 10（API 29）。低于该版本，或 WebView 内核过旧（缺
`String.prototype.replaceAll`/`Array.prototype.at`/`Object.hasOwn` 任一能力）时，
应用会显示明确的"浏览器版本过旧"提示，而不是白屏或崩溃（[ADR-027](../adr/ADR-027-minimum-webview-baseline.md)）。

## 离线与 PWA

Web 版本可安装为 PWA，断网后仍可继续编辑已打开的项目（[ADR-029](../adr/ADR-029-service-worker-cache-strategy.md)）。
不支持 File System Access API 的浏览器会自动回退到上传/下载模式，不影响核心编辑功能。

## v0.6.0 Beta 以来新增了什么

- **CI 首次真实运行并全绿**：本仓库从只有一次本地提交到真实推送、五个 CI job
  在 GitHub Actions 上首次跑通，过程中发现并修复了五个真实问题（pnpm 版本冲突、
  Node 最低版本抬到 22.18、一处墙钟超时余量、一个真实的撤销/重做竞态缺陷），
  详见 [v0.9.0-ci-first-run.md](./plans/v0.9.0-ci-first-run.md)。
- **内核测试矩阵扩到模块示例与迁移结果**，并新增 Beta 轨（跟随上游 `latest`，
  只可见不阻断）与 Stable Bundle 发布门（[ADR-031](../adr/ADR-031-kernel-matrix-dual-track.md)）。
- **严格 CSP**：构建产物级别断言，无 `unsafe-eval`、无非必要第三方脚本
  （[ADR-032](../adr/ADR-032-strict-csp.md)）。
- **日志脱敏**：新增 `@mcs/logging`，所有 `console.*` 调用统一走脱敏后的
  `createLogger()`，CI 阻断任何绕过。
- **Web 与更新流程的真实浏览器端到端测试**（Playwright + 真实 Chromium）：创建、
  导入、引用替换、规则排序、差异、导出、离线恢复、Bundle 安装/签名失败/版本
  不足/回滚/项目锁定共 12 个场景。
- **性能预算 CI 阻断**：1 MB 语料导入、1000 实体/10000 规则规模操作均有真实
  CI 硬件上标定的阈值（[ADR-034](../adr/ADR-034-perf-budget-ci-calibration.md)）。
- **WCAG 2.2 AA 走查**，对比度断言扩到全部真实令牌组合。
- **敏感字段遮罩全量走查**：全部真实模块的敏感字段覆盖率有专门测试兜底，
  三个导出/分享出口逐一核对过遮罩不外泄。
- **项目标签与搜索**（FR-PROJ-07）。
- **可由用户逐条关闭的规则告警**（FR-VAL-06），关闭偏好持久化在项目里。
- **静态规则解释器**（FR-RULE-06）：为规则列表里的每一行说明它由哪些部分
  组成、大致匹配什么范围——**明确不模拟内核运行时匹配行为**，这条边界在文案
  与代码里都有测试守护。
- **手动导入社区 Schema Bundle**（FR-UPD-09）：仍必须通过全部既有安全检查
  （哈希、格式版本、静态内容检查），唯一豁免签名必须由已知信任锚点签发这一条，
  豁免后持久标记"签名来源未验证"并在 Bundle 管理页与每个使用它的项目上持续
  显示警告，且永远不能进入 Stable 通道。
- **`schema-cli preview` 工具**（FR-SCHEMA-07）：社区贡献者可以在提交签名前
  把一个模块渲染成每字段一行的纯文本，确认控件、必填、遮罩与显示条件符合
  预期——渲染逻辑与应用本身完全相同，不是第二套解释。
- **发布阻断项 CI 映射收口**：PRD §13.5 五条发布阻断项里有四条现在由 CI 机器
  直接回答，映射表见 [docs/release-blockers.md](../release-blockers.md)。

## Bundle 更新源：本次仍不配置远端源

Schema Bundle 的签名验证机制（Ed25519，原生 WebCrypto 优先、不支持时纯 JS 回退，
[ADR-013](../adr/ADR-013-ed25519-verifier-backend.md)/[ADR-028](../adr/ADR-028-pure-js-ed25519-backend.md)）
已在真实浏览器端到端测试里验证过完整的检查更新→安装→回滚链路。但**本次 RC 仍然
有意不配置任何远端 Bundle 更新源**——应用自带的内置 Bundle 可离线使用；手动导入
（见上）是本版本内获取社区 Bundle 的唯一途径。

## 已知缺口

**本节逐条列出——不在发布说明的其它地方隐藏或淡化这些缺口。**

- **Android 端到端测试未接入 CI**：`connectedAndroidTest`（真实 UIAutomator）
  基础设施已就绪，但受阻于一个环境相关的 UI 时序问题，未能让全部场景稳定通过，
  目前仍只由本机模拟器人工执行，详见
  [v0.9.0-android-e2e-evidence.md](./plans/v0.9.0-android-e2e-evidence.md)。
- **PRD §13.5 第五条发布阻断项（Android 保存/重新打开可靠性）仍由人工回答**：
  与上一条同一根因，决策是不为此在无 KVM 的免费 CI runner 上引入第三方模拟器
  action，详见 [docs/release-blockers.md](../release-blockers.md)。
- **上游监控自动化（`tools/upstream-watch`）改期 1.x**：Mihomo 上游发布新版本
  时，目前仍需人工核对是否需要跟进模块 Schema，未建自动化监控。
- **YAML 导出的完整格式化偏好未实现**：行宽与缩进已可配置，其余导出偏好
  （FR-YAML-08 原文列出的其它选项）改期 1.x。
- **NFR-PERF-05（Web Worker 主线程长任务）的真实浏览器测量为 Partial**：
  已有真实浏览器测量基础设施，尚未在全部关键路径上补齐阈值断言。
