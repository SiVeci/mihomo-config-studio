## FR-AND-06：权限清单断言 —— 源码级 + 产物级

**源码级**（`tools/android-manifest-check`，已接入 CI，见 #12）：

```
$ node tools/android-manifest-check/dist/index.js apps/android/android/app/src
OK   apps\android\android\app\src\main\AndroidManifest.xml
```

**产物级**（本地跑，CI 无 Android SDK 不跑这一层）：

```
$ aapt2 dump permissions apps/android/android/app/build/outputs/apk/debug/app-debug.apk
package: studio.mihomoconfig.m0spike
uses-permission: name='android.permission.INTERNET'
permission: studio.mihomoconfig.m0spike.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
uses-permission: name='studio.mihomoconfig.m0spike.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION'
```

两层均确认：仅 `INTERNET` 权限与 AndroidX 自动生成的
`DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`（广播接收器导出声明，非存储/VPN
相关），无 `READ/WRITE_EXTERNAL_STORAGE`、无 `BIND_VPN_SERVICE`、无
`android.net.VpnService`、无 `FOREGROUND_SERVICE*`。

## NFR-PERF-01 与 Android 最低支持版本

冷启动基线数据、测量方法与最低版本冻结结论见
[ADR-014](../../adr/ADR-014-android-minimum-supported-version.md)。摘要：
两台设备 `TotalTime` 中位数（7 次采样）均远低于 2.5s 阈值（API 29：412ms；
API 36：586ms），最低支持版本冻结在 **API 29（Android 10）**——本机已验证的
最旧系统镜像，同时也是硬约束下限。
